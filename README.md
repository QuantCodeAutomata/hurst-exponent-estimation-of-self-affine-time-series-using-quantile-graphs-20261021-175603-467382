## Overview

This repository reproduces the four core experiments from the paper, which
introduces the **quantile-graph (QG) method** for estimating the Hurst
exponent of self-affine time series.

The central idea:
1. Map a time series to a directed weighted graph by partitioning its amplitude
   range into Q equal-frequency quantile bins (nodes) and recording lag-k
   transitions between bins.
2. The mean absolute graph-node jump length Δ(k) scales as a power law
   k^H, where H is the Hurst exponent.
3. The log-log regression slope provides an estimator H_QG.
4. For stationary fractional Gaussian noise, cumulative summation first
   converts the series to a fractional Brownian motion before applying the
   estimator.

```bash
bash reproduce.sh
```

This will:
1. Install requirements.
2. Run the full pytest suite (61 tests).
3. Execute each experiment script, saving plots and JSON metrics to `results/`.

## Key Parameters

| Parameter | Paper default | This run (user override) |
|-----------|--------------|--------------------------|
| Q (quantile bins) | 50 | **10** |
| T (series length) | 10 000 | 10 000 |
| N realizations | 100 | 100 |
| Lag range k | 1–1 000 | 1–1 000 (20 log-spaced) |
| Random walks per W_k | 100 | 100 |
| Walk length L | not stated | 200 |
| Generator | Abry-Sellan wavelet | Davies-Harte (fbm package) |

The user explicitly overrode `Q = 10` (paper default: 50) and the exp3
comparison uses `Q ∈ {10, 20}` (paper: `{50, 100}`). Results with Q = 10
show higher estimation errors than reported in the paper, especially for
large H.

## Experiments

### Exp 1 — Transition Topology
Reproduces Fig. 2 of the paper. Plots 6×6 heatmaps of the lag-1 transition
matrix W₁ for β ∈ {−1, −0.5, 0, 0.5, 1, 2}, confirming anti-diagonal
dominance for anti-correlated series and diagonal dominance for correlated ones.

### Exp 2 — Hurst Estimation from Mean-Jump Scaling (fBm)
Reproduces Figs. 3–4. Demonstrates that Δ(k) ∝ k^H over >2 decades in log-log
space; OLS slope estimates H with 95% CI.

### Exp 3 — Sensitivity to Q
Reproduces Fig. 5. Compares absolute Hurst estimation error for Q = 10 vs
Q = 20 across β ∈ {1.0, 1.2, …, 3.0}.

### Exp 4 — fGn Extension via Cumulative Summation
Tests the cumulative-summation preprocessing that enables the QG method to
estimate H from stationary fractional Gaussian noise series.
